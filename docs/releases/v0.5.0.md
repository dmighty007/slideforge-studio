# SlideForge 0.5.0

Released 3 November 2026.

## Landscape Explorer

- New built-in plugin under **Plugins → Physics & maths → Landscape f(x, y)**.
- Equations evaluated by a safe parser, or CSV matrices / `x, y, value` rows on a grid.
- Heatmap, contour, combined and rotatable 3D surface views.
- Hover/tap values, keyboard rotation, zoom and reset; plot gestures stay separate from slide navigation.
- Explicitly save a camera angle for the export still. PowerPoint, PDF, PNG and standalone/shared views retain the saved picture.
- Missing-data masking, nonuniform coordinates, fixed color scales and optional sampled-minimum subtraction.
- Optional live-view plugin API with lifecycle cleanup; other plugins keep their existing behavior.

CSV input is limited to 60 KB and 81 coordinates per axis. Scattered-point interpolation and interactive standalone HTML/share playback are not included.

See the [usage guide](../PLUGINS.md#landscape-explorer).

## Also included since 0.4.1

- PowerPoint/Keynote import improvements: merged tables, shape and table navigation actions, more picture formats, preset geometry, fonts, SmartArt placement and equation fallbacks.
- Open supported presentation files from the desktop command line.
- Show recorder and presentation timer.
- Improved animation parity in standalone web exports and presentation navigation fixes.
- Expanded documentation and playable showcase decks.

Complex imported decks should still be reviewed before presenting: custom page proportions, some animation/transition details and native editing of imported graphics remain limited.

## Validation

- Landscape numerical, missing-data, live interaction, resizing, save/reload, disabling and cleanup checks passed.
- Actual landscape PowerPoint and PDF exports generated and inspected.
- 34 existing plugin browser regressions and 9 backend plugin tests passed during implementation.

This Git release does not imply a PyPI upload.
