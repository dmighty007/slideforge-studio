# SlideForge 0.7.1

Released 9 November 2026.

## Text editing

- Double-click selects a whole word even when part of it is styled differently; double-click and drag extends the selection word by word. Triple-click selects the line or bullet, and a fourth click the whole box.
- The selection stays highlighted while you type a font size, pick a colour or use the toolbar, and stays selected after a style is applied, so several styles can be applied in a row. Repeated changes to the same text reuse one styled span.
- Bold, italic, underline and strikethrough buttons follow the selected text, not the whole box, and show its state.
- PowerPoint's shortcuts while editing: Ctrl+B/I/U, Ctrl+Shift+X (strikethrough), Ctrl+= and Ctrl+Shift+= (subscript, superscript), Ctrl+] and Ctrl+[ (font size), Ctrl+Shift+L/E/R/J (alignment), Ctrl+\ (clear formatting). Arrow keys step the font size field.
- Typing `- `, `* ` or `1. ` at the start of an empty box starts a list. Alt+Shift+↑/↓ moves a bullet; Tab indents all selected bullets.
- A text box can be resized while its text is being edited, and entering editing no longer shifts the text.

## Imported PowerPoint animations

- Imported builds are listed in the Motion panel: change the effect, trigger, click order, duration and delay, or remove them. The ✎ button opens the preset picker to replace an animation.
- On-click animations with the same order play on the same click, in order. Changing the animation of a shape imported as several objects (such as a box and its text) changes all of them.
- The slide's transition can be set from the Motion panel, for one slide or all of them. Transitions set on a PowerPoint layout or master are imported.
- Bullet builds can be turned on for any box with several paragraphs.
