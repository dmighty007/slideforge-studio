# SlideForge 0.7.0

Released 5 November 2026.

## Present a PDF

- Open a PDF as slides: **Import → PDF** on the start screen, **Open PDF as Slides** in the command palette, or `slideforge talk.pdf`. A Beamer talk, or a deck someone sent as PDF, is ready to present.
- Each page becomes a slide whose background is a sharp picture of the page, on the page setup closest to its proportions (Beamer's 4:3, 16:9 and 16:10 match exactly).
- Links in the PDF still work while presenting: to another page (that slide) or to a web or mail address.
- Presenter view, notes, the laser pointer, the chalkboard and the timer work as on any slide, and objects and builds can be added over a page.
- Password-protected PDFs and ones over 400 pages are refused with a clear message.

The page's text is part of the picture: it cannot be edited or searched. Beamer overlays (`\pause`) are separate PDF pages, so each step becomes its own slide.

See [Present a PDF](../guides/import-export.md#present-a-pdf).

## Presenter view

- "This slide" restarts on every slide; it kept the previous slide's time.
- Next Slide shows the next slide as the audience first sees it, with click builds, bullets and diagram reveals still to come, not fully built.

## Web (ZIP) export

- Links in text boxes work again (web, mail and slide links).
- Next, Previous, Home and End step over hidden slides, and a hidden backup slide that a link opens is kept in the export.

## Documentation

- A features page and guides for scientific objects, presenting and imports/exports, with current pictures of the app.
- Showcase decks (3, 30 and 42 slides) built with the real editor and exports.

## Validation

- Backend (197) and desktop (58) tests, `ruff`, and the frontend syntax check pass; CI passed on the release commit's code.
- The PDF import was tested end to end in the browser (pages, page setup, a page link followed while presenting) and tried in the desktop app.
- Browser suites against the desktop app's server: UI smoke (22), phase 2, animations and the full regression run (344) pass. A first run had 3 regression failures that did not recur on a full rerun; their names were not recorded.
- The strict docs build passes, and the 0.7.0 wheel builds with the new files.

**Not tested:** sharing through the public Cloudflare tunnel, and very large PDFs (hundreds of pages) for import time.

This Git release does not imply a PyPI upload.
