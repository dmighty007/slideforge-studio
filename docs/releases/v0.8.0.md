# SlideForge 0.8.0

Released 10 November 2026.

## Projects

- The start screen has two tabs. **Home** starts a deck, picks a theme or imports a file; **Projects** lists every saved presentation, to sort by date or title, search, open or delete.
- **Ctrl+O** (Cmd+O on a Mac) opens the Projects tab from the editor instead of the browser's file picker. The toolbar's Projects button and the account menu's "Saved projects" open the same place.
- **Open project tabs:** each project you open gets a tab above the canvas, shown once two or more are open. Each tab keeps its own slide position and undo history. Closing a tab saves the project and never deletes it; if the save fails, the tab and its edits stay.
- Deleting the open project from the start screen says so and asks you to open or start another one.

## Saving

- Starting a new project or opening another one saves the open project first. If that save fails, the switch is refused and nothing is lost (before, edits made just before switching could be dropped).
- A project changed in another window is no longer overwritten. Autosave stops and says *"Changed in another window. Reload to get that version, or press Ctrl+S to keep yours."* Before, the next autosave replaced the other window's work while both windows said "All changes saved".

## Fixes

- **Line spacing** applies to plain, bulleted and imported PowerPoint text, undoes in one step, and the field shows the spacing the text is actually drawn with.
- **Continuing without an account** closes the sign-in dialog instead of leaving it over the editor; a click outside it closes it too.
- **Presenter view** no longer shows "Click to add title" prompts on the speaker's copy of the slide.
- **A web server run without accounts** hides the Home and Projects buttons, which did nothing there. New Project replaces the one local deck and offers Undo.
- **The first chart or object on a blank title slide** comes in at full size, without the "slide is busy" notice.
- **The start screen** keeps keyboard focus inside it (Tab no longer reaches the editor behind), and its tabs sit in the header so more of the start options fit on screen.
- **Command palette:** Save, Share a view-only link and Keyboard Shortcuts are listed.
- Deleting the only slide says why nothing happened.

## Validation

- `ruff`, the frontend syntax check, backend checks and backend tests (197) pass; desktop tests 58 passed, 7 skipped.
- Browser suites against a server set up as in CI (accounts off): UI smoke 25 passed, phase 2 and animations pass, regressions 309 passed. One smoke run had the Charts menu's Line Chart button time out; it passed on the rerun.
- Against the desktop app's server: the saving and desktop-only regressions (57), the landscape suite, the start screen (12), open project tabs (including a failed save and Ctrl+O) and the Projects tab pass.
- Checked by hand in the browser: every fix above, including two windows editing the same deck, and the start screen at 1440×900, 1366×768 and phone width.

**Not tested:** the desktop app's own window (only its server), macOS (Cmd+O) and Windows. At 1366×768 the import buttons on the start screen still need a scroll.
