# Prepare the story, then rehearse the controls

<p class="sf-page-lead">Use motion to introduce an idea, live objects to answer a question, and notes to keep the argument on track.</p>

## Build in meaningful steps

**Object animations** change something within a slide. **Slide transitions** change how the next slide arrives.

1. Select the object and use its motion settings.
2. Choose an automatic entrance or a click-triggered build.
3. Add emphasis, exits or supported motion paths where they help the explanation.
4. Rehearse the sequence in presentation mode.

Diagrams and bullet lists can be revealed progressively. Use the [animation showcase](../showcase/animations.md) to try the available kinds of motion.

## Present with notes and live objects

Use the play button to start the show. Arrow keys move through supported builds and slides; **Escape** returns to editing.

Open **presenter view** with **P** for the current/next slide and notes. Try the laser pointer, spotlight and chalkboard when they help direct attention.

Native molecule and landscape controls remain available on the active slide. Their gestures are handled by the object rather than advancing the show. Landscape camera changes made during a talk are temporary; save the intended starting view in the editor.

## Use the timer

Press **T** during the show to show or hide the timer. Hiding it does not stop it. **Shift+T** pauses or resumes the clock.

Set a talk length with **Set Talk Length…** in the command palette (**Ctrl+K**) or the recording dialog to use a countdown. The setting is kept with the presentation. The timer is also available in presenter view.

## Record locally

Use **Record** beside the play button, or **R** while presenting. Choose the microphone and whether to include slide media audio, then follow the browser's capture prompt.

The show starts with a countdown. The recording can include the slides, builds, microphone and supported media audio. The result is offered as a local WebM download; it is not uploaded by the recorder.

| Key | During a presentation |
| --- | --- |
| **R** | Start recording, or pause/resume an active recording |
| **Shift+R** | Stop the recording while leaving the show running |
| **T** | Show/hide the timer |
| **Shift+T** | Pause/resume the timer |
| **P** | Open presenter view |
| **Escape** | Exit presentation mode |

Capture support varies by browser and desktop runtime. Where element capture is supported, the video can contain just the slide stage. Other environments can record a larger shared window or offer audio-only recording when screen capture is unavailable. Check a short recording before the real talk.

## A short rehearsal checklist

- Confirm which clicks reveal content and which advance the slide.
- Test the first frame, saved view and autoplay settings of live objects.
- Open presenter view and check the notes.
- Listen to a short recording if you will capture the talk.
- Open your exported fallback on the computer you will use.
