# Your first presentation

[Install SlideForge](install.md) first, then open it from your applications menu.
You can work locally without creating an account.

## 1. Create a presentation

From the start screen, create a new presentation. Give it a name so you can find it
again. Use **New Slide** to add slides, and select a thumbnail on the left to edit one.

## 2. Add your content

Use the toolbar above the canvas to insert text, an image, a chart, or an equation.
Select an object to change its settings in the properties panel. Drag it on the canvas
to position it.

For a first example, insert a chart and edit its data table. If you prefer equations,
insert an equation and enter LaTeX. The [capabilities showcase](showcase/capabilities.md)
shows the kinds of figures you can build.

## 3. Try presenting

Use the play button in the top toolbar to enter presentation mode. Use the arrow keys
to move through the slides and animation steps. Press **Escape** to return to editing.
The [animation showcase](showcase/animations.md) demonstrates builds and transitions.

## 4. Export a copy

Open **Export** in the top toolbar and choose the format your audience needs:

| Format | Use it for | What to expect |
| --- | --- | --- |
| PowerPoint | Continuing work in PowerPoint | Text and charts remain editable; scientific plugins, equations, and molecules export as pictures. |
| PDF | Reading or printing | A static copy of your slides. |
| Web (ZIP) | Presenting in a browser | Extract the ZIP, then open its HTML viewer; it can play offline. |

Keep your SlideForge presentation so you can edit the original figures later.
